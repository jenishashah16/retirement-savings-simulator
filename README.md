# Retirement & Investment Simulator

## Project Overview

The Retirement & Investment Simulator is a frontend web application that helps users visualize how their investments grow over time using different financial instruments such as SIP, Fixed Deposits, and lump-sum investments. The system allows users to input parameters like investment amount, expected returns, and time period to understand potential outcomes and make informed financial decisions.

## Tech Stack
- React
- TypeScript
- Vite
- HTML
- CSS

## Key Features

- SIP, FD, and Lump Sum investment calculations
- Interactive input fields for investment parameters
- Real-time investment summary and return estimates
- Clean and user-friendly interface
- Built using modern frontend technologies
